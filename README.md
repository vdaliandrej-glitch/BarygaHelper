# BarygaHelper

Клиентский мод для Fabric: локальный каталог косметики и поиск игроков с нужной косметикой на сервере **DiamondWorld**.

> Мод работает только при подключении к `diamondworld.pro` (и его поддоменам). Используйте его в рамках правил сервера.

## Возможности

- **Каталог косметики.** Откройте серверный список косметики — мод сам считает предметы со страницы, пролистает остальные и сохранит всё с редкостью (обычная → мифическая).
- **Поиск по игрокам.** Выберите нужные предметы, нажмите «Добавить в базу» — мод по очереди откроет профили игроков из таба (`/profile <ник>`) и проверит разделы «голова», «аксессуары», «компаньоны». Скрытые инвентари отмечаются как «только витрина».
- **База игроков** с сортировкой по совпадениям, редкости, уровню, дате регистрации и нику; фильтр по эффектам на косметике.
- **Чёрный список** и вкладка **«Найдено»** для уже найденных предметов.
- **Перепроверка своего инвентаря** с автолистанием.

## Управление

| Действие | Клавиша / команда |
|---|---|
| Открыть окно мода | `I` |
| Остановить поиск / автолистание | `F8` или `/df stop` |

Клавиши меняются в настройках управления Minecraft.

## Установка

1. Установите [Fabric Loader](https://fabricmc.net/use/) ≥ 0.19.5 для Minecraft **26.2**.
2. Положите в папку `mods`:
   - [Fabric API](https://modrinth.com/mod/fabric-api) ≥ 0.161.0;
   - `BarygaHelper-<версия>.jar` из папки [release](release).
3. Нужна Java 25+.

## Где лежат данные

Всё хранится локально, мод ничего не отправляет в интернет.

| Файл | Что внутри |
|---|---|
| `config/diamond-finder/catalog.json` | каталог косметики |
| `config/diamond-finder/players.db` | база проверенных игроков |
| `config/diamond-finder/blacklist.txt` | чёрный список |
| `config/diamond-finder/found.txt` | отмеченные как найденные предметы |
| `config/BarygaHelper.cfg` | настройки локального журнала сообщений |

### Журнал исходящих сообщений

Опциональный локальный лог ваших сообщений и команд в `logs/BarygaHelper/message/ГГГГ-ММ-ДД.log`.
**По умолчанию выключен** (`message.enabled=false`). Аргументы команд авторизации (`/login`, `/register`, `/changepassword`, `/2fa` и т. п.) всегда заменяются на `[REDACTED]`.

## Сборка из исходников

```bash
./gradlew build
```

Готовый jar появится в `build/libs/`. На Windows используйте `gradlew.bat build`.
Нужен JDK 25.
